
# One-Day Python Basics Training Agenda

## ⏰ Time: 09:00 – 16:15 (4 Sessions, 90 minutes each)

---

| Time          | Activity              |
|---------------|------------------------|
| 09:00 - 10:30 | Session 1              |

| 12:15 - 13:00 | 🍽️ Lunch Break         |
| 13:00 - 14:30 | Session 3              |

| 14:45 - 16:15 | Session 4              |

---

## 🎓 Prior Knowledge

Participants should have:
- Basic understanding of programming concepts (e.g., variables, loops, functions)
- No prior Python experience is required

---

## 🧠 Target Audience

- Beginners with little to no Python experience
- Developers transitioning from other languages

---

## 🗂️ Session Overview

### 🔹 Session 1: Python Fundamentals
- Introduction to Python
- Syntax, indentation, comments
- Variables and data types (int, float, str, bool)
- Operators and expressions
- Interactive exercises using `print()` and basic math

---

### 🔹 Session 2: Control Flow
- Conditional statements (`if`, `elif`, `else`)
- Loops: `for` and `while`
- Loop control statements (`break`, `continue`)
- Practice exercises: simple decision-making programs

---

### 🔹 Session 3: Functions and Data Structures
- Defining and calling functions
- Parameters and return values
- Built-in vs user-defined functions
- Introduction to Lists, Tuples, Dictionaries
- Hands-on: building reusable functions

---

### 🔹 Session 4: A short introduction to OOP principals
- References and objects
- Accessing attributes and methods using the Dot-Operator
- A simple user-defined class
