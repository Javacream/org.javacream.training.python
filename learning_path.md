 
# Learning path for Python training series
## Prerequisites
### Technology
* Internet access, especially access to [GitHub](https://GitHub.com/Javacream)
* Local Python installation version 3.x
* Visual Studio Code with installed Python extension from Microsoft
* Microsoft Teams, the use of a headset is recommended
* Note
  * If the technical requirements cannot be met by the customer, remote computers can be used. A separate connection test is necessary in advance
### Participants
* Confident handling of Microsoft Teams
* Basic IT terms (What is data, what is a server? File system and basic operation of Windows-Cmd, Powershell or Linux Shell)
* Basics of programming
  * Notes
    * No in-depth knowledge of another language such as Java or C# is meant here. Theoretically, knowledge of spreadsheets is also sufficient
    * If candidates for the participants do not yet have any programming affinity, it should be considered offering a day of “Programming basics”. A preliminary survey of participants' knowledge is recommended; the questionnaire and evaluation can be taken from Cegos
 ### Learning method
* Presentation
* Discussion
* Independent exercises, proportion of exercises approx. 30%
* Program examples and sample solutions are provided per implementation in a GitHub repository. The commit history documents the learning progress in a comprehensible way
  * Note: The repositories are also available after the end of the training courses
* Learning objective check through final exercise
* Handouts for independent follow-up in PDF format
* Use of a curated list of additional resources, in particular online documentation and tutorials
### Process
* 5 blocks with the topics
  * Python for beginners
  * Python for advanced users
  * Python data analysis & visualization
  * Object-oriented programming with Python
  * Python and machine learning
* 8 teaching units per block spread over 2 days
  * Seminar times 9:00 - 17:00 with morning and afternoon break 20' each and lunch break 1:15 
* Implementation with Microsoft Teams
## Contents
Each main block lasts about 90 minutes
### Python for beginners
* Introduction
    * Introduction of the presenter and the participants
    * Presentation of the learning path, where do we start, where does the journey go? Expectations
    * First contact with Python
        * Writing a first program with Visual Studio Code
        * Starting programs, integrated terminal
    * Overview: AI tools for code generation
    * Online resources
* Variables
  * Declaration and use of variables
  * `print` and `input`
  * Dealing with errors 
  * Efficient programming with VSC
    * Python editor (syntax highlighting, code assist) 
    * Debugger: breakpoints, interface, viewing and changing values during debugging
* Data types and operators
    * Literals for character strings, integer and floating point numbers
    * Mathematical operators as well as + and * for numbers and character strings
    * Type conversion with `str`, `int` and `float`
    * Formatted strings f'...'
* Control structures
    * Boolean data type
    * `if-else`
    * Boolean algebra
    * Error handling with `try-except`
  
* Data container
    * Categorization: List, Set, Dict, Tuple, Range
    * Creation of data containers with literals and BuildIn functions
    * Iteration with for
    * Methods of data containers
* Functions
    * Definition: name, parameter, return value
    * Calling functions
    * Methods vs BuildIn functions vs self-defined functions
* Final exercise
### Python for advanced users
* Modules
    * import
    * Scope of commands of some standard modules
        * os
        * datetime
        * math
    * Overview pip and PyPi
* File operations
    * Reading and writing text files
    * Error handling
    * The csv and json modules
* Objects and references
    * Memory model of the Python interpreter with stack and heap
    * Variables as references to objects
    * Function parameters and references
* Detailed knowledge
    * Functions
        * *args and **kwargs
        * Lambda expressions
    * Collections
        * Comprehensions
        * Sorting
    * `with` statement
* Testing
    * The unittest module
    * Writing tests
        * A short introduction to the syntax of inheritance
        * Writing TestCases
* Accessing WebServices
    * The `requests` module
    * Accessing a RESTful WebService
    * Reading and writing with GET and PUT
* Accessing a relational database
    * The `mysql-connector` module
    * Brief introduction to the `select` and `insert` clauses of SQL
    * Reading and writing to a simple table
* Final exercise
### Python Data Analysis & Visualization
* Introduction
  * From raw data to the story: the basic process of data analysis
 * The pandas module: Installation, documentation, range of functions
  * Jupyter notebooks vs script program
* First work
  * Importing CSV, JSON, Excel
  * Series and DataFrame
  * Description and categorization of data
Visualization with Pandas and Matplotlib
  * Overview of supported chart types
  * Histograms, line and pie charts
* Preparation of raw data
  * Recognition of missing or incorrect values
  * Data cleansing
* Data evaluation
  * Filtering, formatting and transforming
  * Grouping and aggregation
* Case studies and practical examples
* Final exercise
### Object-oriented programming with Python
* Basic principles of object-oriented programming
  * Data structures, associations and inheritance
  * Modeling with class diagrams
  * Implementation of a class in Python
* Objects and classes
  * Constructors in detail
  * Attributes and methods
  * The class object
* Associations and inheritance
* Dunder methods
  * Encapsulation
  * `__repr__`, `__eq__` and `__hash__`
* An overview of the classes in the Python libraries 
* Expert knowledge
  * Abstract elements
  * Protocols
  * Multiple inheritance / mixins
* Final exercise
### Python and machine learning
* Introduction
  * Definition of terms and embedding in the complex of “artificial intelligence”
  * Differentiation and similarities to statistics
* Basics of machine learning
  * Difference between supervised and unsupervised learning methods
  * Fundamentals and application examples of classification, regression, clustering 
  * Training and evaluating models
* Introduction to statistics
  * Descriptive statistics (mean, median, deviation and variance)
  * From the sample to the generality: inferential statistics
  * Regression analysis
* Classification methods
  * K-Nearest Neighbors (KNN)
  * Decision trees
* Machine learning with Python libraries
  * Descriptive statistics with Pandas
  * Scikit Learn
* Neronal networks
* From correlation to causality: evaluation of models
* Final exercise
